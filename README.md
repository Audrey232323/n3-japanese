# 日文N3練習（n3-japanese）

手機優先、可離線使用的日文 N3 互動練習網頁（PWA）。

**👉 開啟：https://audrey232323.github.io/n3-japanese/**

## 內容

| 區塊 | 內容 |
|---|---|

| 單字 | 1054 個 N3 單字（13 個主題、詞性篩選），🗂 SRS 記憶卡（間隔重複）、翻卡、選擇測驗、單字表 |

## 用手機開啟、加到主畫面

### iPhone／iPad（Safari）
1. 用 **Safari** 開啟上面的網址。
2. 點下方的「分享」按鈕（方框加向上箭頭）。
3. 選「**加入主畫面**」→「新增」。
4. 之後從主畫面的「日文N3」圖示開啟，會以全螢幕 App 的方式執行。

### Android（Chrome）
1. 用 **Chrome** 開啟網址。
2. 點右上角「⋮」→「**安裝應用程式**」或「**加到主畫面**」。
3. 從主畫面圖示開啟。

### 電腦
Chrome／Edge 網址列右側會出現「安裝」圖示，點一下即可安裝；也可以直接用瀏覽器開啟。

## 離線使用
- 第一次開啟後，所有內容都會存進裝置快取，**沒有網路也能使用**。
- 有網路時會優先載入最新版本（3 秒內沒回應就改用快取），所以更新後重新開啟就是新版。

## 進度保存
- 進度（答題紀錄、錯題、SRS 記憶卡、弱點假名…）存在這台裝置的瀏覽器裡（localStorage），不會上傳。
- 換手機或清除瀏覽器資料前，請到「成績」→「備份與還原」按「匯出進度」，把內容存起來；到新裝置貼上後按「匯入」。
- iPhone 上「Safari 分頁」和「主畫面 App」的資料是分開的，建議固定從主畫面圖示開啟。

## 歌詞
歌詞受著作權保護，所以這個公開網站**不收錄任何歌詞**。在歌曲頁按「🔍 搜尋歌詞」找到歌詞後複製，回到 App 貼上並儲存即可；歌詞只存在你這台裝置的瀏覽器裡，也會一起包含在「備份與還原」的匯出內容中。
- 假名由內建的斷詞程式 kuromoji 自動標註。第一次開啟歌詞時會下載約 18 MB 的字典，之後離線也能用。
- 影片播放需要網路。

## 發音
朗讀使用裝置內建的日語語音（Web Speech API）。若沒有聲音，請在手機設定中下載日語語音：
- iPhone：設定 → 輔助使用 → 朗讀內容 → 聲音 → 日文
- Android：設定 → 文字轉語音 → 安裝日文語音資料
